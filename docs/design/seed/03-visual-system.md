# 03. Visual System

## Typography

Use a compact, readable documentation scale.

Recommended:

- page title: 36-44px, 1.15 line-height, 700 weight
- section h2: 24-28px, 1.25 line-height, 650 weight
- subsection h3: 18-20px, 1.35 line-height, 650 weight
- body: 15-16px, 1.7 line-height
- small/sidebar text: 13-14px
- code: 13px, 1.6 line-height

Use Korean/Latin-friendly sans fonts such as Pretendard, Noto Sans KR, Inter, or system UI.

## Writing

Use direct instructional writing.

Good:

- “Use this pattern when...”
- “Avoid this when...”
- “This component is used for...”
- “The title is required; description is optional.”

Avoid vague marketing copy and emotional adjectives.

## Color

Use a neutral documentation palette:

- background: white or near-white
- subtle surface: #F8F9FA / #F9FAFB
- border: #E5E7EB / #E6E8EB
- strong text: #111827 / #171717
- default text: #374151 / #3F3F46
- muted text: #6B7280 / #71717A
- code background: #F6F8FA / #F7F7F8

Use accent color sparingly for:

- active nav
- selected tab
- primary action
- focused input
- small semantic highlight

## Spacing

Use a 4px-based rhythm:

- 2, 4, 6, 8, 10, 12, 16, 20, 24, 32, 40, 48, 64

Recommended layout spacing:

- top nav height: 56px
- page top padding: 40-56px
- section gap: 40-64px
- heading to body: 12-20px
- paragraph gap: 16px
- card padding: 16-24px
- sidebar group gap: 24-32px
- table cell padding: 10-14px vertical, 12-16px horizontal

## Radius And Surfaces

- small controls: 6px
- cards/code blocks: 10-12px
- badges/pills: 999px
- dialogs/sheets: 16-24px when needed

Use white surfaces with 1px borders. Avoid deep shadows.
